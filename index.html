OmniScribe Transcription Engine

Converts audio recordings into accurate text with speaker diarization.

Designed for field researchers and multi-session interviews. The tool accurately detects distinct speakers (Interviewer vs. Artisan), preserves native regional scripts (Hindi, Bengali, Maithili), and creates a side-by-side English translation without omissions.

  • Interviewer vs. Artisan Attribution: Automatically labels who asked the questions and who responded.
  • Side-by-Side Bilingual Dialogue: Read native script on one column and genuine English translation in the other.
  • Cross-Folder Synthesis: Collates multi-part interviews of the same artisan into unified dossiers.
  • Consolidated Exports: Download clean Word (.docx), PDF (.pdf), and Markdown reports.

Laboratory Philosophy

Why MANO-LAB Exists

Software does not always need to be a monolithic product. MANO-LAB operates as an incubator for specialized tools, hyper-focused utilities, and experimental prototypes.

Each application lives in its own isolated directory with zero unnecessary inter-dependencies. This ensures that experiments can be built rapidly, iterate independently, and deploy smoothly without breaking existing tools.

Contribute on GitHub
01. Static-First

Every app starts as a self-contained static interface deployable directly to edge CDNs without fragile build pipelines.

02. Local-First Privacy

Heavy computation and sensitive audio files stay on your machine with direct local engine connectivity.

03. Single Registry

New apps are integrated by adding one folder and one entry to the central manifest.

04. Zero Vanity

No fake metrics, no artificial clutter. Pure functionality designed with editorial craftsmanship.
